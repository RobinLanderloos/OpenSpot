# Listings that don't fit are hidden, not dimmed

Non-fitting listings are removed from the Browse tab's results, with a "Showing X of Y" line so an empty list never looks like a broken addon. Dimming and sorting fits to the top was rejected: it means re-styling the recycled scroll rows on every refresh of Blizzard's list, which is more fragile, and the user wanted the noise gone. No per-row open-spots badge in v1.
